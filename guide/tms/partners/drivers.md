# 司机

**合作伙伴 → 司机** 管你自己的司机：账号、车辆、状态。

顶部搜索框支持**按姓名、邮箱、电话或驾照**找人。

## 两种加人的方式

右上角有两个按钮，用途不同：

| 按钮 | 什么时候用 |
|---|---|
| **邀请司机** | 司机要用 LINE 做[送达确认](../driver/pod)。生成注册链接发给他，司机自己用 LINE 注册 |
| **添加司机** | 你直接替司机建档。**姓名和电话必填** |

**邀请司机**点下去会生成链接并自动复制，直接粘到 LINE 里发给司机即可。链接约两天
过期，过期重新生成。

:::note
提示「该组织尚未配置 API 密钥」时，先到机构设置里生成 API 凭证，再回来邀请。
:::

## 车辆决定能派什么活

司机档案上记着他的车辆和车辆类型。这不是填着好看的——[配送规划](../delivery/planning)
里派司机时，下拉里**只列出车辆类型和这趟配送匹配的司机**。

司机明明在岗却派不上，先回来看他的车辆类型对不对。

## 启用和停用

司机有 **启用 / 停用** 状态，可以随时切换。停用的司机不参与派单。

离职的司机建议停用而不是删除——历史配送和轨迹还挂在他名下。
