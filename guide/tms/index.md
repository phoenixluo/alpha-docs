# TMS 用户指南

Alpha Cargo TMS 管的是货从**发出**到**签收**的全过程：录运单、排车配送、司机扫码
回传状态、最后结算收款。

这份文档写给用它干活的人。要调接口的请看[开发者指南](/tms/)。

## 谁用它，用哪一块

| 角色 | 主要在哪儿 |
|---|---|
| 录单 / 客服 | **运单**：建单、导入、查件、打印标签 |
| 调度 | **配送**：规划排车、指派司机、盯轨迹 |
| 司机 | 手机扫码页；送达确认在 LINE 里完成 |
| 财务 | **账单**：价格表、发票、付款、对账 |
| 管理员 | **设置**：机构信息、服务、团队成员与权限 |
| 收件人 | 公开查件页——不需要账号 |

## 两条主线

一票货进了系统之后，走的是两条并行的线：**运单**记录这票货是什么、从哪到哪；
**配送**记录哪辆车、哪个司机、哪一趟把它拉走了。一趟配送通常装很多票运单。

理清这两个词，后面的菜单才不会看串。

还有两个词容易反着理解，界面上叫：

- **客户**（Contractors）—— 把货交给你运的人，也就是你的上家。
- **承运商**（Subcontractors）—— 你把货交出去让它运的人，也就是你的下家。

## 看不到某个菜单？

TMS 的菜单是**双重门**：

1. **套餐功能** —— 你所在组织买了哪些功能，没买的菜单整个不出现。
2. **账号权限** —— 你个人被授予了哪些权限，没有的菜单也不出现。

所以同一个组织里，两个人登录后看到的菜单可能不一样。缺菜单时先找组织管理员，
而不是怀疑自己点错了。
