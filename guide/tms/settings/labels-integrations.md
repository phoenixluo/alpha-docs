# 标签模板与集成

## 标签模板

**设置 → 标签模板** 管面单的版式。

点 **创建模板** 新建，进入可视化编辑器排版。模板列表里可以**设为默认**——
[打印标签](../waybills/labels)时没有特别指定就用默认那张。

已经是默认的再点一次会提示"该模板已是默认模板"。

:::warning
**默认模板删不掉**，会提示"无法删除默认模板"。要删它，先把另一张设为默认。
:::

删除模板会二次确认。

### 给承运商配专用模板

不同[承运商](../partners/subcontractors)对面单要求不一样。添加承运商时可以为他配
专用模板，交货给他时就按对方的版式打。

## 第三方集成

**设置 → 集成** 配置第三方承运商和支付渠道的对接凭证。

页面上每个渠道是一张卡片。**套餐里没有的渠道显示为锁定状态**——需要开通才能配置，
见[界面导航](../getting-started/navigation)里讲的套餐门。

填的是对方给你的凭证。填好之后，相关的服务就能通过这个渠道下单了。

:::note
自己的系统要对接 TMS，是另一个方向——用 **设置 → 机构 → API 凭证** 里的密钥，
见[开发者指南](/tms/authentication)。
:::
