# 对账

**账单 → 对账** 把银行流水上的入账，和系统里的付款记录配对——确认钱确实到了。

## 怎么用

1. 点 **导入流水**，上传银行对账单。
2. 系统把流水条目列出来，你把每一条对到它结算的那笔付款上。
3. 顶部可以按 **收款账户** 筛，搜索框支持**按描述、付款人或参考号**查找。

页签可以在 **全部** 和未配对之间切换。

## 对不上的常见原因

| 现象 | 多半是 |
|---|---|
| 流水里有，系统里没有 | 客户付了但没人在发票上记录收款 |
| 系统里有，流水里没有 | 记了收款但钱还没到，或者记错了 |
| 金额差一点 | 银行手续费，或者客户少付/多付 |
| 找不到对应客户 | 客户转账时没写参考号 |

:::tip
让客户转账时带上**参考号**，对账会轻松很多——搜索框直接按参考号就能定位。
:::

## 和付款核验的区别

两件事容易混：

| | [付款核验](./payments) | 对账 |
|---|---|---|
| 依据 | 客户上传的**银行水单** | 你从银行下载的**对账单** |
| 确认什么 | 这张水单是真的、对得上这张发票 | 钱确实进了你的账户 |
| 谁先谁后 | 收款当时 | 通常是月末或定期 |
