# WMS 仓储管理

**文档编写中。**

WMS 管的是货在仓库里的那一段：入库上架、库存、拣货、出库。它和 TMS 共用同一套
组织与账号体系——同一个组织下，仓库作业和运输作业看到的是同一批货。

## 与 TMS 的关系

两个产品在**收发货**这一步对接：TMS 里的配送单位对应到 WMS 的具体仓库，出库完成后
TMS 侧的运单状态随之推进。这条链路的对接方式写在
[开发者指南](/tms/)里。

## 现在能看什么

- 需要接口对接的，看 [TMS 开发者指南](/tms/)。
- 需要 WMS 操作说明的，请先联系我们——这份文档正在补。
