# 寄件人账户

**合作伙伴 → 寄件人账户** 是通过你发货的一个个主体。运单挂在它下面，账单也算在
它头上——**没有寄件人账户，货进不来**。[导入运单](../waybills/import)时必填的
「寄件账户代码」就是它的代码。

## 列表

页面顶部三个统计：**账户总数**、**启用账户**、**未启用账户**。

搜索框支持**按姓名、公司、代码、邮箱或电话**查找——**输入后按回车**才会搜。右边可以
按 **类型** 筛。

表格列出：代码、姓名、公司、联系方式、类型、**账单周期**、**付款条件**、状态。

## 添加账户

右上角 **添加寄件人账户**。也可以用 **导入** 批量建。

关键字段：

| 字段 | 说明 |
|---|---|
| **代码** | 这个账户的唯一标识，导入运单时要填的就是它 |
| **类型** | 账户分类，在 **配置寄件人账户类型** 里维护 |
| **账单周期** | 每周 / 每两周 / 每月 / 自定义 |
| **付款条件** | 到票即付、Net 7 / 15 / 30 / 45 / 60 / 90、自定义 |

账单周期和付款条件决定了这个客户的账单怎么出、什么时候到期，见账单章节。

## 详情页里还有什么

点开一个账户，除了改资料，还有两块：

- **代码区间** —— 给这个账户分配一段运单号区间，它的货用这段号。
- **钱包** —— 预付余额。充值后从余额里扣，也可以手工调整（需要钱包调整权限）。

## 账户类型在哪配

页面上的 **配置寄件人账户类型** 按钮跳到类型维护页。

:::note
这一页**不在设置菜单里**，只能从寄件人账户页面点进去。见[界面导航](../getting-started/navigation)。
:::

## 启用和未启用

未启用的账户不能再收新货，但历史运单和账单都在。客户暂停合作时停用它，不要删。
