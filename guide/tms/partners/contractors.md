# 客户

**合作伙伴 → 客户** 是你的**上家**——把运输业务交给你做的机构。

从对方的角度看，你是他的[承运商](./subcontractors)；同一条合作关系，两边各看一半。

## 列表

顶部 **搜索客户** 按名称找，右边 **按状态筛选**：

| 状态 | 意思 |
|---|---|
| 启用 | 正常合作中 |
| 待处理 | 关系还没确认 |
| 已暂停 | 暂停合作 |
| 未启用 | 未激活 |

列表列出客户名称、联系方式和状态。点进去看详情。

## 客户和运单

客户是运单筛选条件之一。在[运单列表](../waybills/list)里按 **客户** 筛，就能只看
某一家上家交过来的货。

## 客户和寄件人账户的区别

两个都是"给你发货的人"，但层级不同：

| | **客户** | **寄件人账户** |
|---|---|---|
| 是谁 | 把业务整体外包给你的**机构** | 具体下单发货的**账户** |
| 用来干嘛 | 业务关系、结算对象 | 挂运单、算账单、管钱包 |
| 在哪建 | 对方在平台注册后建立关系 | 你自己维护，见[寄件人账户](./sender-accounts) |
