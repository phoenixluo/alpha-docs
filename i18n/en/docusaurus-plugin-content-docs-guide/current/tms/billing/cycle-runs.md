# Cycle runs

**Billing → Cycle Runs** is the **history** of automatic invoicing — the system gathers
billing on the cycle set in [billing profiles](./billing-profiles), and each run leaves a
record.

This page is for looking, not doing.

## What's on it

Three figures at the top: **Total Runs**, **Completed**, **Total Amount**.

The list below can be filtered by **Status**, and each row shows what that run processed,
for how much, and whether it succeeded.

## When you'd come here

- **A customer says they never got their invoice** — check whether the run happened and
  whether it completed.
- **The amount looks wrong** — check what period that run covered.
- **A run failed** — the status shows it; get in touch if it needs sorting out.

## Setting the rhythm

Cycles are set in [billing profiles](./billing-profiles): weekly, biweekly, monthly or
custom. Change the profile and later runs follow the new cycle.
